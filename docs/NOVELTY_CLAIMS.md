# Novelty Claims: Allowed, Open, and Disallowed

## Allowed now

- EOD is a proposed database-native abstraction combining current possible-world uncertainty with explicit admissible evidence capability.
- EOD queries return typed resolution objects: answer certificates, evidence obligations/policies, or impossibility certificates.
- The repository defines query-relative obstruction and resolution-antiprovenance objects.
- The finite reference model has an executable algebra and planners.
- Same current query view can have different EOD resolution status when evidence capabilities differ.
- A finite EOD instance can exhibit a strict fixed-vs-adaptive evidence-cost gap.

## Open — requires proof/literature support

- EOD is a conservative extension of a particular incomplete-database formalism.
- EOD has operators or certificate objects not definable in access-method frameworks.
- EOD admits database-specific tractable fragments not already known in testing/planning.
- Resolution antiprovenance is historically novel as a database provenance object.

## Do not claim

- first database system to acquire data;
- first database theory with future actions;
- first adaptive information-acquisition framework;
- first use of possible worlds plus sensing;
- adaptive evidence planning itself is new;
- weighted covering/minimum test selection is new;
- strict expressive superiority over access-method answerability or epistemic planning.

These restrictions remain until contradicted by proof and a systematic literature review.
